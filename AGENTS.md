# Workspace Instructions & Memory

## Style & Presentation Rules
- **No Emojis**: Do not use emojis anywhere in the project (UI components, text messages, notifications, error envelopes, logs, code, or documentation). Use vector SVG icons or clean semantic labels/badges instead.
- **Lazy Senior Dev / Minimal Code**: Write minimal, robust code. Do not add unnecessary abstractions or dependencies.
- **Rich Design System**: Maintain clean typography, high-contrast dark/light tokens, and smooth CSS transitions.
